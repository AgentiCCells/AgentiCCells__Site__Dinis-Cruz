Use with AI

This site has two plain-text files for AI assistants, so a language model can read it without the page layout getting in the way.

llms.txt

/llms.txt is a short Markdown file at the root of the site. It says what the site is and lists its pages, so an assistant knows where to look. The format is a public proposal for sites to describe themselves to language models.

index.md

/index.md holds the content of the site as one Markdown file. Paste its address, or its text, into an assistant and ask it questions about the site.

How to use them

  1. Copy the address of one of the files above.
  2. Give it to your AI assistant, or open the file and paste its text in.
  3. Ask your question. The assistant can then point to the page each answer came from.

index.md holds the full text of the home, CV, recommendations and sources pages. It links to this page and to behind-the-scenes but does not repeat them.
